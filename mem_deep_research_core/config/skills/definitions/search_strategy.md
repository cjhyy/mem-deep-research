# 搜索策略指南

当需要搜索信息时，请遵循以下策略以获得最佳结果：

## 1. 搜索顺序优化

按照信息新鲜度和相关性，推荐以下搜索顺序：

1. **聊天记录** (chat) - 最新的对话可能包含最相关信息
2. **备忘录** (memo) - 用户的个人笔记和总结
3. **邮件** (email) - 正式沟通和决策记录
4. **日历** (calendar) - 会议和事件信息
5. **外部搜索** - 当内部数据不足时

## 2. 查询优化技巧

- **使用关键词**: 用关键词而非完整句子搜索
- **同义词扩展**: 尝试相关的同义词
- **时间过滤**: 使用时间范围缩小结果
- **来源过滤**: 指定特定数据源

## 3. 结果验证

- 检查结果的时效性（优先使用最新信息）
- 交叉验证多个来源
- 总结时注明信息出处

## 4. 无结果处理

如果搜索无结果：
1. 尝试更宽泛的关键词
2. 去掉时间限制
3. 扩大搜索范围到更多数据源
4. 询问用户提供更多线索

---

## 示例

**情境 1**: 用户问：帮我找一下上周和张三讨论的项目进度

**参考做法**:
1. 搜索聊天记录，关键词"张三 项目进度"，时间限制"上周"
2. 如果聊天记录不够，扩展搜索备忘录中的相关笔记
3. 综合多个来源的信息进行总结

---

**情境 2**: 用户问：查一下公司的报销政策

**参考做法**:
1. 聊天记录中关于"报销"的讨论
2. 备忘录中可能保存的政策文档
3. 邮件中 HR 发送的政策通知
