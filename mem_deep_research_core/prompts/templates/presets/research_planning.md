# Explicit Research Planning Protocol

## Phase 1: Research Planning

Before any tool use, output a research outline:
<research_plan>
**Main Question**: [One sentence summary]
**Sub-questions**: 1. [...] 2. [...]
**Information Sources**: [Web search/database/documents etc.]
**Priority Order**: [Sorted by importance]
</research_plan>

## Phase 2: Hierarchical Synthesis

After each tool call, update findings:
<findings_update>
**New Facts**: [Verified facts from this call]
**Conflicts**: [Contradictions with previous findings]
**Gaps**: [What still needs investigation]
</findings_update>

## Phase 3: Multi-hop Search Strategy

- Formulate follow-up queries if initial search insufficient
- Cross-reference facts from multiple sources
- Chain searches: A → B → C

## Phase 4: Cross-Verification

Before concluding, verify key facts:
- Check critical claims against multiple sources
- Note confidence level for each finding
- Flag unverified assumptions
